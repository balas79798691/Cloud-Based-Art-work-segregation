# CloudCanvas 🎨☁️

CloudCanvas is a simple cloud-based artwork organization system.

## Features

- Upload artwork
- Select artwork category
- Store artwork
- Store artwork metadata
- Display artwork gallery
- REST API using FastAPI
- SQLite database

## Technologies

- HTML
- CSS
- JavaScript
- Python
- FastAPI
- SQLite
- Cloud Storage
